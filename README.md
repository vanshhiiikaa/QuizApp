# 🧠 Python Quiz App 🎯

A simple **Quiz Application built using Python** that tests your Python knowledge through multiple-choice questions. 🚀

## ✨ Features

✅ User name input and welcome message  
✅ Multiple-choice Python questions  
✅ Automatic answer checking  
✅ Score calculation  
✅ Final score display  
✅ Exit option during quiz  
✅ User-friendly console interface  

## 🛠️ Technologies Used

🐍 Python 3  
📚 Lists  
📖 Dictionaries  
🔁 Loops  
🔀 Conditional Statements (`if-else`)  
⚠️ Exception Handling  
📦 Modules
